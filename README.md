# Голос — локальна аудіостудія

Озвучення текстів і монтаж аудіо на Mac з Apple Silicon. Застосунок використовує **OmniVoice через MLX**, працює локально та не потребує API-ключів.

## Встановлення та запуск

Потрібні Mac з Apple Silicon, Python **3.10–3.12** і кілька гігабайтів вільного місця. Інтернет потрібен для початкового встановлення залежностей і завантаження моделі.

1. Завантажте репозиторій або склонуйте його на комп’ютер.
2. Відкрийте **`setup.command`** — він створить середовище й завантажить модель.
3. Відкрийте **`start.command`** — студія відкриється в браузері за адресою [127.0.0.1:8765](http://127.0.0.1:8765).

Залишайте вікно запуску відкритим під час роботи. Для наступних запусків достатньо `start.command`.

Ті самі дії можна виконати в терміналі з папки проєкту:

```sh
./setup.command
./start.command
```

## Як вимкнути студію

1. Збережіть потрібний монтаж і дочекайтеся завершення генерації або збереження аудіо.
2. Перейдіть у вікно **Термінала**, у якому запустили `start.command`.
3. Натисніть **Control+C** (⌃C, не Command+C) й дочекайтеся повідомлення `Finished server process` або повернення запрошення командного рядка. Після цього вікно можна закрити.

Закриття вкладки браузера **не зупиняє сервіс**. Якщо на момент зупинки ще триває генерація, сервіс може чекати на її завершення.

Якщо повторний запуск `start.command` показав «Студія вже запущена», це вікно лише відкрило браузер. Для вимкнення скористайтеся початковим вікном Термінала, у якому працює сервер.

Якщо початкове вікно загубилося, відкрийте **Моніторинг системи (Activity Monitor)**, знайдіть процес Python, який слухає порт `8765`, і завершіть його. PID цього процесу можна перевірити в Терміналі:

```sh
lsof -nP -iTCP:8765 -sTCP:LISTEN
```

Для наступного запуску знову відкрийте `start.command`. Збережені голоси й готові аудіо залишаються в `data/`.

## Озвучення

1. Відкрийте **«Озвучення»** й уведіть текст — до 3 000 символів.
2. Виберіть голос, українську або англійську мову, якість і швидкість мовлення.
3. Виберіть **WAV, FLAC або MP3** та натисніть **«Створити аудіо»**.
4. Прослухайте або завантажте результат у розділі **«Мої аудіо»**.

Для MP3 доступні 64, 96 і 128 кбіт/с; початкове значення — 64 кбіт/с. Швидкість мовлення змінюється від **0,7× до 1,3×** зі збереженням висоти голосу.

Щоб додати точну паузу, вставте тег у текст:

```xml
Зроби повільний вдих. <break time="10s" /> А тепер видихни.
```

Тег додає тишу й не озвучується. Також підтримуються мілісекунди, наприклад `<break time="500ms" />`. Задані паузи зберігають тривалість при зміні швидкості мовлення.

## Власні голоси

У розділі **«Мої голоси»** натисніть **«Додати голос»**, завантажте аудіофайл або зробіть запис із мікрофона. Укажіть назву, мову та точний текст усього запису, після чого збережіть голос.

Мінімальна тривалість зразка — **3 секунди**; для початку рекомендовано 5–15 секунд чистого мовлення. Максимальний розмір файлу — **64 МБ**. Підтримуються WAV, FLAC, AIFF, MP3, M4A, WebM та OGG. Використовуйте власний голос або голос із дозволом його власника.

## Аудіоредактор

Редактор починається з **однієї порожньої доріжки**. Додайте аудіо з «Мої аудіо», файлу або мікрофона. Кнопка **«＋ Додати доріжку»** створює наступну доріжку; фіксованого обмеження їхньої кількості немає.

- Перетягуйте доріжки по часовій шкалі для накладання або послідовного об’єднання.
- Натисніть **олівець** праворуч, щоб відкрити обрізання, початок на шкалі, гучність, наростання й затухання.
- Увімкніть **«Циклічне програвання»**, щоб повторювати обраний фрагмент. За замовчуванням він повторюється до кінця спільної шкали; за потреби задайте власну тривалість.
- Натисніть **кошик**, щоб прибрати доріжку з монтажу.
- Прослухайте мікс і збережіть його **новим треком** або **замість використаного початкового запису** з «Мої аудіо».

Чернетка монтажу зберігається в цьому браузері. Кнопка **«Редагувати»** біля готового аудіо додає його до редактора.

Аудіоредактор не має фіксованих меж тривалості джерел, міксу, зміщення чи повторення, а також розміру імпортованого файлу. Практичні межі залежать від вільного місця на диску, пам’яті браузера та аудіоформату; довший монтаж потребує більше часу на обробку. Великі WAV автоматично використовують RF64. Гучність кожної доріжки регулюється від **0 до 400%**.

Озвучення експортується у **24 кГц, моно**, мікси — у **48 кГц, стерео**. При збереженні міксу у MP3 виберіть **64, 96 або 128 кбіт/с** у полі «Якість MP3»; початкове значення — 64 кбіт/с. Вибір запам’ятовується в цьому браузері.

## Збереження даних

Модель, голоси, готові аудіо та база даних зберігаються в папці **`data/`**. Для резервної копії зупиніть студію й скопіюйте цю папку. Чернетки тексту та монтажу зберігаються в браузері.

Після встановлення генерація й монтаж працюють без інтернету. Видалення запису з «Мої аудіо» видаляє його аудіофайл без кошика.
